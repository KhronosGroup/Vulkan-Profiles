# Vulkan Profiles Toolset

The *Vulkan Profiles Toolset* is a collection of tools delivered with the [Vulkan SDK](https://www.lunarg.com/vulkan-sdk/) for Vulkan application developers to leverage *Vulkan Profiles* while developing a Vulkan application[cite: 7].

* **[Vulkan Profiles Tools Overview](./OVERVIEW.md)**: Discover the components and how they work together[cite: 7].
* **[vkprofiles commande lines reference](./profiles/README.md)**: Command-line guide and options reference for the `vkprofiles` tool (`validate`, `schema`, `convert`, `merge`, `library`, `doc`).
* **[Vulkan Profiles Tools Whitepaper](./doc/Vulkan-Profiles-Tools-Whitepaper.pdf)**: Detailed whitepaper about the Vulkan Profiles Tools[cite: 7].
* **[Vulkan Profiles Documentation](https://vulkan.lunarg.com/doc/sdk/latest/windows/profiles_definitions.html)**: *Tables to compare profiles capabilities*[cite: 7].
* **[Change Log](./CHANGELOG.md)**: The history of *Vulkan Profiles Toolset* releases[cite: 7].
* **[Contributing](./CONTRIBUTING.md)**: How to contribute to the *Vulkan Profiles* repository[cite: 7].
* **[Bug reports](https://github.com/KhronosGroup/Vulkan-Profiles)**: Open a GitHub issue when you encounter a bug[cite: 7].

## Version Tagging Scheme

Updates to this repository which correspond to a new Vulkan specification release are tagged using the following format: `v<`_`version`_`>` (e.g., `v1.3.266`)[cite: 7].

**Note**: Marked version releases have undergone thorough testing but do not imply the same quality level as SDK tags[cite: 7]. SDK tags follow the `vulkan-sdk-<`_`version`_`>.<`_`patch`_`>` format (e.g., `vulkan-sdk-1.3.266.0`)[cite: 7].

This scheme was adopted following the `1.3.266` Vulkan specification release[cite: 7].
